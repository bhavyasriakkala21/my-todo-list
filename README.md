# 🌷 My To-Do List

A simple and interactive to-do list website built as my first web development project.

## 🌐 Live Demo

[Click here to use My To-Do List](https://bhavyasriakkala21.github.io/my-todo-list/)

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🎨 Clean and colorful user interface
- 📱 Responsive layout for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
